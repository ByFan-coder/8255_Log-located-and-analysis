# v1.0.0 — 首个正式版本

适用于 T18D（8255）及类似 QNX / Android 平台的离线日志定位与分析。

## 功能

- 先核对故障时间、启动周期、校时和日志覆盖，明确缺失及解码限制后再分析。
- 优先联查 QNX slog2、systeminfo、QNXRunInfo.tar.gz；按故障选择图形、显示、I²C 与触摸关键词。
- 疑似屏端问题先询问是否解析 display_log；现场状态推断结合视频、照片或后续测量。
- 故障屏与零件号、版本一一对应，完整保留 hw_ver、sw_ver、tp_ver、supplier_code 及日志定位。
- QNX / 屏端未定位后继续查其他相关层；非驱动、非屏端问题简析并建议流转模块。
- 按编辑器规则处理 CRLF、LF、CR 混合换行，附只读行号定位工具。

## 安装与附件

- `t18d-8255-debug-v1.0.0.zip`：完整技能目录，解压后复制整个技能文件夹到目标 agent 的技能目录。
- `SHA256SUMS`：ZIP 的 SHA-256 校验清单。

详细步骤见仓库 README。其他 agent 需支持 SKILL.md，或显式读取指令及引用文件。行号工具需要 Python 3.10+，无第三方依赖。

## 验证范围

行号工具测试覆盖混合换行、空行、无结尾换行、Unicode分隔符、UTF-8 BOM / UTF-16 / GB18030、gzip、重复匹配、CLI 定位及只读保持。打包验证包含名称、引用、元数据及 ZIP 逐文件一致性。

日志解码仍依赖项目格式和工具；结构与工具测试不代表现场根因已被自动验证。历史经验已抽象化，不附原始日志或聊天标识。
