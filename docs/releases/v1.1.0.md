# v1.1.0 — 源码/协议核对与简短 Bug 表单去重

## 新增功能

- 检查当前分析目录的 `code/` 和 `protocol/`，查找项目参考源码、头文件、配置及通信协议；缺失、为空或缺少相关材料时询问是否添加。
- 将参考源码、协议版本及适用屏型与现场材料核对；版本未确认时保留限制，不以参考实现代替现场证据。
- 建立当前目录的 `bug_table.md`，以简短表单记录现象、版本、时间/启动实例、关键证据、结论及关联ID。
- 简单去重：同一事件更新原ID，相似问题标记疑似重复并关联；不自动合并、删除或关闭Bug，不自动修改缺陷系统。
- 随包提供空白 Bug 索引模板与去重参考。真实记录、项目源码和协议不进入技能发布包。

## 安装

下载 `t18d-8255-debug-v1.1.0.zip` 和 `SHA256SUMS`。解压后将整个 `t18d-8255-debug` 目录安装到目标 agent 的技能目录。升级前先比较并备份自定义修改。

具体步骤和调用示例见仓库 README。Python 行号工具要求 Python 3.10+，仅使用标准库。

## 验证

通过行号工具的8项测试、10个技能文件的结构和内部引用检查，以及ZIP逐文件校验。保留v1.0.0已有的时间覆盖优先、QNX优先、跨层分析、屏幕信息对应和编辑器计行规则。

去重仅针对实际读取的本地索引，不代表全项目查重；结构检查不代表真实现场根因分析已自动验证。
